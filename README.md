# Lumina AI - Premium UI Generation Platform

Lumina AI is a high-performance, futuristic AI-powered React template designed for seamless digital experiences. Built with a focus on **Clean Code**, **Enterprise-level scalability**, and **Immersive UI/UX**.

Perfect for SaaS startups, AI tech companies, and modern digital agencies.

## 💎 Key Features

- **Interactive AI Workspace:** A fully functional-looking Chat UI with "Push" sidebar and typing indicators (Gemini/ChatGPT style).
- **Zero-Blink Animations:** Highly optimized Framer Motion transitions with no layout shifts or hydration flashes.
- **Glassmorphism & Neon Glows:** Modern dark theme with subtle ambient background glows.
- **Responsive Layout:** Pixel-perfect across all devices (Desktop, Tablet, Mobile).
- **Clean Architecture:** Modular component structure making it incredibly easy to scale and modify.

## 📄 Pages Included (9 Pages)

1. **Home** - High-converting landing page with animated text and floating inputs.
2. **Workspace / Chat AI** - Interactive AI prompt interface with sidebar history.
3. **Features** - Bento-grid style layout highlighting core platform capabilities.
4. **Pricing** - Monthly/Annually toggle with beautifully highlighted tiers.
5. **Showcase** - Masonry-style gallery for community generations.
6. **About Us** - Behind the scenes, team members, and core values.
7. **Testimonials** - Infinite scrolling marquee for user reviews.
8. **Auth** - Sleek Login & Registration split-screen.
9. **404 Error** - Custom page not found design.

## 🛠️ Built With

- **Framework:** React.js 19 (Vite)
- **Styling:** Tailwind CSS v4 _(Latest)_
- **Animations:** Framer Motion
- **Routing:** React Router Dom v7
- **Icons:** Lucide React

## 🚀 Quick Start

1. Clone or extract the repository.
2. Open your terminal and navigate to the project directory.
3. Install dependencies:
   npm install
4. run the website:
   npm run dev
